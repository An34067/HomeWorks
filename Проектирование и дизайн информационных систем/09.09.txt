no-cache - не сохранять в кеш и не использовать без подтверждения
no-store - не сохранять на диск
ust-revalidate - запрет на использование при потери 
связи с сервером
public - все могут сохранять данные (в том числе прокси, cdn и так далее)
immutable - файл никогда не изменится (брайзер сразу использует
данные из кеша без подтверждения)


1. Создайте 4-е location ведущие к /images/, /api/, /profile/ и /
2. Создайте соответствующие папки по пути www/site1/....
3. Запрос к /image/ должен возвращать html с текстом: "Our gallery" и заголовками
X-Location с названием папки. Ответ должен быть неизменяемым и публичным. Cache-Control
4. Запрос к /api/ должен возвращать html с текстом: "It's API boy" и заголовками
X-API-Version с произвольным числом и X-Location с названием папки. Ответ должен 
не сохранять в кеш и на диск.
5. Запрос к /profile/ должен возвращать html с текстом: "My profile" и заголовками
X-Location с путем файла и Say-My-Name с вашей фамилией. Ответ должен быть приватным.
